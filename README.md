# HBM4/HBM4E TSV Parasitics — FYP

Research repository for Q3D Extractor, Maxwell 3D validation and Gaussian Process Regression of GSG/GSSG/GSGSG TSV capacitance.

Status: CA2 baseline of 261 accepted Q3D ML observations (including nine frozen GSGSG blind cases). Twelve paired lossless Q3D–Maxwell checks completed; substrate/reference matrix mismatch remains unresolved. Proposed targeted DOE V2 expansion of 90 cases is **not yet simulated**.

This initial README will be expanded with audited documentation, reproducibility guidance and an append-only iteration log. Do not treat Q3D as experimentally validated ground truth.
